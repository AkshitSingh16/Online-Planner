# 🗓️ Online Planner

An Online Planner is a full-stack web application developed using **Django REST Framework** for the backend and **React.js** for the frontend. The application helps users manage their daily tasks and schedules efficiently through a simple and user-friendly interface.

## 🚀 Features

- User-friendly interface
- Create new tasks
- View all tasks
- Update existing tasks
- Delete completed tasks
- REST API integration using Django REST Framework
- Responsive frontend built with React
- Backend powered by Django
- SQLite database support

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript
- Axios

### Backend
- Django
- Django REST Framework
- Python

### Database
- SQLite

## 📂 Project Structure

- **Frontend:** React.js
- **Backend:** Django REST Framework
- **API Communication:** REST APIs
- **Database:** SQLite
